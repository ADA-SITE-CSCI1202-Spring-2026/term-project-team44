to run the file in IntelliJ IDEA(macOS):
go to: Toolbar> file> project structure> modules
and set src as source folder
then go to: Toolbar> file> project structure> libraries
and import javafx library
then, create a run configuration. customize following text for your computer and enter it as VM option:
--module-path "[PATH TO JAVAFX LIB ON YOUR COMPUTER]" --add-modules javafx.controls,javafx.fxml --enable-native-access=javafx.graphics
Then choose aresbase.Main to be Main class.
The code is ready to run.
